Jellyfin Oscars Settings

OMDb provides the awards data used by this plugin. Get a key from omdbapi.com. Your full key is never shown in the UI or written to plugin logs.
When enabled, the plugin checks eligible movies for Oscar wins and nominations and updates their metadata during refresh.
Lower values refresh Oscar data more often but use more OMDb requests. Recommended default: 24 hours.
Allows the plugin to refresh Oscar data automatically on a schedule instead of waiting only for manual library refreshes.
Controls how many movies are processed in one refresh run. Small libraries: 5-10. Large libraries: 20-50.
Maintains a collection containing movies in your library that won at least one Oscar.
Maintains a collection containing movies in your library that were nominated for an Oscar.
When enabled, Oscar-winning movies will also appear in the nominees collection.
Adds the plugin's default poster artwork to Oscar collections only when they do not already have a primary image.
Scans existing movies in your library and adds Oscar tags where applicable.
Rebuilds Oscar collections immediately based on current library data and Oscar tags.
